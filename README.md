## 📌 Deskripsi Singkat
**PawCare AI** adalah platform web asisten kesehatan hewan peliharaan (kucing & anjing) berbasis Multi-Modal AI (teks & foto) dan *Evidence-Based Veterinary Medicine*. Platform ini dirancang untuk memberikan pertolongan pertama darurat, triase medis (Traffic Light Alert), rujukan jurnal kedokteran hewan terindeks SINTA, serta lokasi klinik vet 24 jam terdekat.

---

## ✨ Fitur Utama
1. 🔴 **Multi-Modal AI Symptom & Photo Analyzer**: Mengunggah foto kondisi fisik anabul + ketik gejala untuk analisis triase medis instant (Merah/Kuning/Hijau).
2. 📚 **Evidence-Based Citations**: Rujukan ilmiah dari jurnal veteriner SINTA / IPB / UGM / Merck Vet Manual untuk mencegah halusinasi AI.
3. 🩹 **Interactive First-Aid Checklist**: Panduan pertolongan pertama darurat di rumah + peringatan larangan medis.
4. 🏥 **24-Hour Emergency Vet Finder**: Pencari lokasi dan telepon klinik hewan darurat 24 jam terdekat.
5. 📱 **Mobile-First Glassmorphic UI**: Antarmuka dark glassmorphism modern, responsif di HP, dan pemicu kamera langsung.
6. 🎬 **Micro-Animations System**: Laser scanline animation, emergency pulse beacon, spring slide-up, dan tactile pill button bounce.

---

## 🛠️ Tech Stack
* **Frontend**: HTML5, Vanilla CSS (Glassmorphism Design System), Vanilla JavaScript (ES6+)
* **Typography**: Google Fonts (*Outfit* & *Plus Jakarta Sans*)
* **Icons**: Lucide Icons
* **AI Engine**: Google Gemini 1.5 / 2.0 Flash API (via Google AI Studio)
* **Deployment**: Vercel / Netlify
